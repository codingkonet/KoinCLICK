# KoinCLICK — Simple Multi-Currency Budget Manager

**Your money, mastered in a single click.**

- **Web App:** React 19 + TypeScript + Vite + Tailwind CSS
- **Windows Desktop App:** `.NET 8.0` + `WebView2` (`release/KoinCLICK-Windows/KoinCLICK.exe`)
- **Android App:** Native Android Wrapper (`release/KoinCLICK-Android/KoinCLICK.apk` & `KoinCLICK.aab`, Target SDK 36)
